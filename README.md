# E-commerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data to understand
revenue performance, customer behavior, product categories,
delivery performance, and payment methods.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- GitHub

## Dataset

The dataset contains e-commerce order information including:

- Order ID
- Order Date
- Customer ID
- Product Category
- Region
- Quantity
- Unit Price
- Discount
- Payment Method
- Delivery Days
- Customer Rating
- Revenue

## Key KPIs

- Total Revenue
- Total Orders
- Total Quantity Sold
- Average Order Value
- Average Customer Rating
- Average Delivery Days
- Revenue by Category
- Revenue by Region
- Monthly Revenue

## Analysis

The project analyzes:

1. Monthly revenue trends
2. Revenue by product category
3. Revenue by region
4. Payment method performance
5. Customer ratings
6. Delivery performance
7. Quantity sold
8. Discount impact

## Visualizations

Charts were created using Matplotlib and Seaborn.

## Conclusion

The analysis provides insights into sales performance,
customer behavior, product categories, and operational
performance.
